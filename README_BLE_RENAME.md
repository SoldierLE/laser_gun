# 蓝牙改名功能说明

## 功能概述
本项目新增了蓝牙设备名称动态修改功能，支持通过手机APP远程修改镭射枪的蓝牙设备名称。

## 协议实现

### 特征值定义
- **0xABE1**: 用于接收手机下发的蓝牙名称修改命令
- **0xABE2**: 用于向手机反馈蓝牙名称修改结果

### 数据格式

#### 手机下发改名命令 (0xABE1)
```
格式: 0x68 + [数据字节] + 0x16
示例: 0x68 0x01 0x02 0x03 0x04 0x05 0x16
对应名称: LG102030405
```

#### 设备反馈改名结果 (0xABE2)
```
格式: 0x68 + [错误码] + 0x16 + [校验码]
成功: 0x68 0x00 0x16 0x00
失败: 0x68 0x01 0x16 0x01
```

### 设备名称规则
- 镭射枪设备名称以"LG"开头
- 后面跟随9位数字
- 示例: LG000000001, LG123456789

## 功能特性

### 1. 持久化存储
- 使用NVS (Non-Volatile Storage) 保存设备名称
- 设备重启后自动恢复保存的名称

### 2. 动态更新
- 支持运行时修改设备名称
- 自动更新广播数据
- 重新启动广播使新名称生效

### 3. 错误处理
- 数据格式验证
- 名称长度限制
- 存储错误处理

## 使用方法

### 1. 通过手机APP修改
1. 连接设备蓝牙
2. 发送改名命令到0xABE1特征值
3. 设备自动处理并反馈结果

### 2. 通过代码修改
```c
#include "gun_gatt_server.h"

// 设置设备名称
esp_err_t ret = gun_ble_set_device_name("LG123456789");
if (ret == ESP_OK) {
    printf("设备名称设置成功\n");
}

// 获取设备名称
char device_name[20];
ret = gun_ble_get_device_name(device_name, sizeof(device_name));
if (ret == ESP_OK) {
    printf("当前设备名称: %s\n", device_name);
}
```

## 测试方法

### 1. 使用BLE调试工具
- 连接设备
- 向0xABE1特征值写入改名命令
- 观察0xABE2特征值的反馈

### 2. 测试命令示例
```
设置名称为 LG123456789:
68 01 23 45 67 89 16

设置名称为 LG000000001:
68 00 00 00 00 01 16
```

## 注意事项

1. 设备名称长度限制为20字节
2. 广播数据总长度不超过31字节
3. 改名后需要重新扫描才能看到新名称
4. 建议在设备未连接时进行改名操作
